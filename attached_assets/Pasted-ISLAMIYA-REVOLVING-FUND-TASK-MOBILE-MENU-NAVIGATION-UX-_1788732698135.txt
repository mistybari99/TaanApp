4. LOGOUT MUST NOT BE A PRIMARY TAB
==================================================

IMPORTANT:

==================================================
5. LOGOUT CONFIRMATION
==================================================

Current behavior:
A single tap immediately logs the user out.

CHANGE THIS.

When user taps Logout:

Show a confirmation dialog/modal.

Example:

"Logout করবেন?"

"আপনি কি সত্যিই এই account থেকে logout করতে চান?"

Buttons:

Cancel
Logout

Default/focus should be on Cancel or otherwise avoid accidental confirmation.

Only perform the actual logout after the user explicitly confirms.

A single accidental tap must NEVER log the user out.

After confirmation:
- Perform the existing logout flow.
- Do not change authentication/session architecture.
- Do not modify backend auth logic.
